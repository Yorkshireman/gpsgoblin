# GPSGoblin example activity

`example-activity.gpx` is the public-domain
[Alpine stage on the Tour du Mont Blanc](https://www.viewmygpx.com/sample-gpx-files/mountain-hike/)
from viewmygpx. It contains a 14.8 km hiking route from Les Houches to Les
Contamines via Col du Tricot, with 1,800 trackpoints, elevations, timestamps and
three waypoints.

The source publishes the file under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). It was downloaded
and supplied by the repository owner on 19 September 2026.
